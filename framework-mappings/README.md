# Framework mappings

How Decirance claims map to published guidance. The point is to show that this
**operationalises** existing guidance rather than replacing it — and to let a
reviewer check a specific claim against a specific provision rather than a page
of logos.

Every mapping ends with a **gaps** section that names what is *not* covered.
Those sections are the part worth reading. A mapping with no gaps has not been
done honestly: the reference agent drafts replies under human review, so whole
areas of each framework — societal impact, denial of wallet, lateral movement —
have no claim behind them, and inventing one would defeat the purpose.

Mappings are a claim about someone else's document, so each records the source
version and the date it was checked. A mapping that silently goes stale is
worse than none — it asserts compliance with a document that has moved.
